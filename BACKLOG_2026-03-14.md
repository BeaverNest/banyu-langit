## KNOWN RISKS & ISSUES

### Critical
- **Backfill look-ahead bias**: `idx_fundamental` (PER/PBV/ROE/DER/NPM) hanya single snapshot (2026-03). Backfill scores untuk 2024-2025 pakai data 2026 → Fundamental & Valuation sub-scores TIDAK akurat untuk tanggal lama. Momentum sub-score akurat (computed from per-date price data).
- **IC Momentum negatif**: Composite IC -0.02 (weak). Momentum factor counter-productive di current market. User perlu tune weights (reduce momentum, increase fundamental) atau model perlu rework.

### Medium
- **Backfill performance**: Backfill 1 tahun (240 trade dates × scoring 100+ stocks) bisa 30-60 detik. Tidak ada progress indicator real-time — user hanya lihat "Running..." sampai done.
- **Risk Control DD overshoot**: Tanpa Liquidate checkbox, DD bisa jauh melebihi threshold karena open positions masih jalan sampai exit signal. Perlu edukasi user bahwa DD Freeze = freeze entry, bukan hard DD cap.
- **Baseline comparison compute time**: Backtest dengan scope "Top Score" runs 2x (primary + baseline). Bisa 2x lebih lambat. Untuk range panjang + all stocks baseline, bisa timeout.

### Low
- **Gap detection**: Endpoint ada tapi UI belum. Perlu ditambah di Settings → Database.
- **Sector heatmap**: Kalau `sectoral_movement` tidak di-sync, heatmap kosong. Graceful fallback message ada.
- **localStorage conflict**: Scoring column toggle disimpan di localStorage. Kalau user punya config lama tanpa `industry` column, perlu ↺ Reset.
- **Chart SVG static**: Semua chart (equity curve, IC, macro flow, heatmap, historical PBV) masih static SVG — tidak bisa hover/zoom. Plan: migrate ke QFChart/ECharts.


### Risk Control State Machine (Backtest)
```
NORMAL (max N positions)
  ↓ DD ≥ threshold% OR ConsecLoss ≥ N
FREEZE (0 entry, optional: liquidate all open)
  ↓ Cooldown N days
PROBE (1 position only)
  ↓ Win → NORMAL (reset CL counter)
  ↓ Loss → CL++ → if CL ≥ threshold → FREEZE again
```

### Scoring Model
```
Fundamental (default 30%): ROE×0.3 + ROA×0.2 + NPM×0.3 + DER×0.2 (percentile rank)
Valuation (default 25%):   PER_vs_ind×0.35 + PBV_vs_ind×0.35 + DivYield×0.3
Momentum (default 30%):    MA20%×0.2 + MA200%×0.15 + Ret20d×0.25 + RSI14×0.15 + FNet5d×0.25
Liquidity filter: avg_freq ≥ 10, market_cap > 50B, not suspended
Output: top 100 stocks ranked by composite score (0-100)
```
